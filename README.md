# Zorvo

Zorvo is a free, tiny 2D game engine for Windows with its own beginner-friendly language, ZorvoScript.

- **Download:** get `ZorvoSetup.exe` from the [latest release](https://github.com/py54/Zorvo/releases/latest) or from chromovia.com.
- **Update:** open Zorvo and choose File > Updates.
- **Changelog:** see [CHANGELOG.md](CHANGELOG.md).

This repository only hosts release builds; the source code is private.
